# Rhine Lab 1.2.1

Windows x64 便携正式版。

- 整理设置界面：通用、外观、声音、动态、画质、数据分区，固定分类导航与独立内容滚动，统一间距与深浅主题。
- 可自定义程序内显示的名称，支持恢复默认；外部 EXE、系统窗口和发行包名称不变。
- 可为单篇文档指定模型颜色，支持恢复跟随全局。单篇颜色优先于收藏色和全局配色，阵列、详情和查看器共用同一配置。
- 全新空知识库首次启动提供六篇使用教程。已经初始化的知识库清空后不会反复导入。
- 教程数量与原有四十个基础模型槽位解耦，主体结构和大小保持不变。

下载 RhineLab-win32-x64-1.2.1.zip 并完整解压运行 RhineLab.exe，同页提供 SHA256SUMS.txt。发布包不包含个人知识库。升级前关闭程序并备份整个 RhineLabData，替换程序时保留原知识库。
