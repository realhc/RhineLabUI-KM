# Rhine Lab 1.2.2

Windows x64 便携正式版。

- 修复点击 ACCESS FILE 后简介栏“概述”标题未参与遮蔽显示的问题，使标题与内容按同一节奏出现。
- 移除动态与画质页的“精细设置”折叠，全部选项始终展示。
- 优化开场主图标下方名称的字形比例与间距，改善默认名称及自定义名称的显示。

完整解压 RhineLab-win32-x64-1.2.2.zip 后运行 RhineLab.exe，同页提供 SHA256SUMS.txt。升级前关闭程序并备份整个 RhineLabData，替换程序时保留原知识库。发布包不包含个人文档，全新空知识库首次启动仍提供六篇使用教程。

1.2.0、1.2.1 的 Release 已移除，历史源码标签保留。请使用 1.2.2 获取完整功能与以上修复。
