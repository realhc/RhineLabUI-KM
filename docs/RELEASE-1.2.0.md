# Rhine Lab 1.2.0

Windows x64 便携正式版。完整解压后运行 `RhineLab.exe`，基础知识库与三维终端可离线使用，无需账户、API Key 或另外安装 Node.js。AI 助手、语义搜索与定时文档继续作为可选功能保留。

## 本次更新

- 模型支持导入 PNG/JPEG，正文支持拖放、粘贴与工具栏插图；图片存入本地知识库，正文图片使用标准 Markdown 引用。
- 新增文内大纲、章节进度、快速切换与前进后退，切换时恢复本次会话的阅读位置。
- 新增全局与一至两层局部关系图谱、反向引用、引用去向及未链接提及；编辑时输入 `[[` 可搜索并插入文档链接。
- 可浏览文档旧修订、比较差异、恢复历史或另存副本，保留修订冲突与未保存内容保护。
- 没有自选图片时，按档案分类与稳定编号生成科学等值线、生长流场或精密线路封面。图片位于磨砂盖板与内部结构之间；自选图片提供原图、双色、网点和线稿风格，并加入克制的表面质感与读取信号。
- 设置新增“外观”：原色、统一色、多彩配色与调色盘，原始、缎面、金属、珠光镀层，颜色强度与收藏专属颜色。阵列、详情和查看器同步显示，模型主体结构与全部尺寸保持一致。

## 下载与升级

下载 `RhineLab-win32-x64-1.2.0.zip`，可用同页 `SHA256SUMS.txt` 核对完整性。便携包不包含个人知识库。

升级前关闭程序并备份整个 `RhineLabData`。替换程序文件时保留原有 `RhineLabData`，其中的文档、图片、历史和 AI 任务会继续使用；不要用新建的空知识库覆盖原目录。
