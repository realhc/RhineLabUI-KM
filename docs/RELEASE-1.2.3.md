# Rhine Lab 1.2.3

Windows x64 便携正式版。

- 首次启动仅需填写用户名，保存在本机，后续启动自动沿用。支持中文与空格，最多 32 个字符，无需密码或联网账户。
- 启动身份、终端界面和访问日志改用本地用户名，替换固定示例身份；设置“通用”中可修改，支持设置导入与导出。
- 发布包不预置用户名或个人设置。旧设置没有用户名时，重新载入后会请用户填写。
- 重整 README 的快速开始、功能说明和数据迁移指引，汇总 HANDOFF 并补充后续建议。

保留 1.2.2 的简介标题遮蔽修复、动态与画质选项始终展示，以及自然比例的开场名称。模型结构与尺寸保持不变。

完整解压 RhineLab-win32-x64-1.2.3.zip 后运行 RhineLab.exe，同页提供 SHA256SUMS.txt。升级前关闭程序并备份整个 RhineLabData，替换程序时保留原知识库。全新空知识库首次启动提供六篇教程，附件不包含个人文档。

1.2.2 Release 已移除，历史源码标签与本地归档保留。请使用 1.2.3 获取完整功能及本次更新。
