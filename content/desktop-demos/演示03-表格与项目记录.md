# 表格与项目记录

下面是一张可以直接编辑的演示表格。进入编辑后，点击任意单元格输入内容，右上工具栏会显示增删行列和移除表格的按钮。

## 练习步骤

1. 点击“进行中”所在单元格，把状态改成“已完成”。
2. 点击“＋行”，为一个新事项添加记录。
3. 点击“＋列”，增加一个“完成日期”字段。
4. 使用 Ctrl+S 保存，再切换文档并返回，检查修改是否保留。

## 会议摘录

> 下一次整理时，先确认资料归属，再调整分类内的手动顺序。

- **已确认**：删除分类不会删除正文。
- **待补充**：为新资料填写简洁、可检索的标题。
- **后续操作**：根据需要创建分类，再将整条文档拖入。
