# 代码与技术笔记

代码块保留代码的换行与缩进。进入编辑后，可以框选一段正文，点击“代码块”转换，也可以在已有代码块中继续输入。

## TypeScript 示例

下面的函数只做演示，不会在知识库里执行。

```typescript
interface Note {
  title: string;
  category: string;
}

function describe(note: Note): string {
  return note.category + " / " + note.title;
}

const note: Note = { title: "入门说明", category: "编辑器演示" };
console.log(describe(note));
```

## Python 示例

```python
records = ["标题", "表格", "公式"]
for index, name in enumerate(records, start=1):
    print(index, name)
```

## 技术笔记

- 用标题概括问题，用正文解释结论。
- 用代码块保留可复现的片段。
- 用引用注明当前假设。

> 切换文档会隔离撤销历史；撤销不会带出另一篇文档的内容。
