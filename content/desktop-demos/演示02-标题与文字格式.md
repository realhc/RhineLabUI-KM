# 标题与文字格式

本页在阅读与编辑时都显示排版效果。进入编辑后，框选文字或把光标放进段落，再使用右上方工具栏。

## 二级标题：整理主题

普通正文适合解释内容。**粗体**可以突出关键词，*斜体*可以表达补充说明，++下划线++可以标记需要再次核对的文字，~~删除线~~可以表示已经撤回的内容。

### 三级标题：补充细节

选择这段文字，将段落样式切换为一级、二级、三级或四级标题，再切回正文，观察同一段内容的变化。

#### 四级标题：小结

- 无序列表适合并列事项。
- 可以按 Enter 继续新增条目。
- 连续的列表可以使用工具栏切换样式。

1. 有序列表适合操作步骤。
2. 先选中文字。
3. 再点击对应的格式按钮。

> 引用块适合保存摘录、备注和评审意见。

## 链接示例

[项目 GitHub 仓库](https://github.com/realhc/RhineLabUI)

阅读时点击链接会用系统浏览器打开。编辑时选中链接文字，点击工具栏的“链接”可修改地址；清空地址可以移除链接。

## 快捷键练习

**Ctrl+B** 加粗、*Ctrl+I* 斜体、++Ctrl+U++ 下划线；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
