# 模型外观设置验收

2026-11-01。版本 1.2.0-preview.1，更新源码、本地预览程序与 ZIP，暂不发布 Release。

## 完成内容

设置新增独立“外观”栏：原色、统一颜色、多彩调色盘，原始/缎面/金属/珠光镀层，颜色强度，收藏模型专属色，以及只重置外观的恢复默认按钮。原生颜色选择器和滑块调整时保持控件节点与焦点。编辑统一色、多彩色卡或收藏色会直接启用相应模式。

颜色按稳定档案 ID 分配，收藏色优先。收藏在详情或知识库中切换均即时同步；阵列、详情、返回副本和模型查看器共用同一套设置。偏好保存在本机，支持设置导入/导出与旧设置文件。

## 实现与约束

- 颜色与镀层只扩展现有 fragment shader。没有修改顶点、缩放、部件位置、厚度、折射率、镜头或灯光；标签、墨字和图片不染色。清晰盖板在正面减弱着色，保留下面图片的可读性。
- 多彩由共享实例颜色/强度缓冲提供，跟随实例扩容回绑；镀层只更新 uniform，不按颜色重建材质或新增绘制通道。稳定颜色缓存最多 512 项，静止时不生成新纹理或定时重绘。
- 收回副本在重建材质后按原文档 ID 重新施用外观；查看器完成异步载入时施用最新设置。超级性能材质复用同一可变 uniform 状态。
- 两个 GLB 与此前打包模型逐字节一致。图片平面仍为 2.65×3.05、z=0.17。相同视口、主题、画质和 DPI 的原路径对照中，投影顶角 `[465,313]` 和位置 `[0,-1.9963,-2.17]` 一致。
