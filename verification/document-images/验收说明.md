# Markdown 正文图片验收

日期：2026-10-27

原界面只将 Markdown 图片显示为附件占位。现已支持将本地 PNG/JPEG 拖到正文指定位置，也支持编辑时粘贴剪贴板图片及工具栏“图片”多选导入。按 Ctrl+S 保存。

图片保留原始字节，正文保存标准相对引用，资产位于 RhineLabData/assets/document-images。每次最多 10 张，单张最多 20 MB、3200 万像素，单边最多 16384 像素。删除正文中的图片会保留资产，供撤销、备份和回收恢复使用。
