# 分类刻度目录验证

日期：2026-10-01。仅修改桌面知识库目录与文档到阵列的对应关系，网页实现保持原样。

## 使用

目录旁 ＋ 可创建并命名分类或文档；分类为大刻度，文档为小刻度。分类有文档时可折叠。拖动小刻度可归类，手动排序时可调整顺序。删除分类保留文档至未分类，删除文档保留分类。

## 数据与映射

desktop/directory.mjs 将分类稳定 ID、名称、列号和文档归属保存于 RhineLabData/directory.json。首次运行自动迁移旧分类，不改写 Markdown 正文。分类改名和移除不改文档修订；空分类独立保存。列号持续分配，原有空模型保留；超出五分类、单列超过 32 文档仍有独立对应位置。

## 验证

- TypeScript 编译、桌面 Vite 构建及 Electron Forge 打包成功。
- check-desktop-categories.mjs：旧 40 档案映射一致、独立删除与改名、回收恢复、重启、额外分类、单列 35 文档和空阵列。
- check-desktop-category-ui.mjs：真实 Electron 的新建命名、空分类点击、文档拖放、折叠、改名、独立删除、重启；浅色与暗色小窗口截图；删空知识库仍有三维模型。
- check-desktop-directory.mjs：滚轮、拖动浏览、点击、未保存保护、键盘、排序及暗色小窗口。
- check-desktop-alignment.mjs：既有网页布局、原场景、编辑保存、搜索、回收恢复、离线和隔离回归通过。结果随本目录保存。

测试运行在复制的隔离客户端与知识库中。交付仅更新程序资源，用户 RhineLabData 不参与测试。现有运行中的客户端需要退出后重新启动。
