# 独立桌面版 1.2.0 验证

本轮将仓库收口为 Windows 本地知识库客户端，解除 fork 关系，移除独立站点、PWA、托管和壁纸宿主文件。原作者署名、字体许可、模型与音频来源材料保留。新增图文用户教程，AI 维护规则集中在 AGENT.md。

同时修复恢复加载期间第二次丢失显卡上下文时的重试遗漏；没有修改三维材质、灯光、模型、镜头或知识库布局。

## 检查结果

- TypeScript、内容、文件仓库、分类事务、动态阵列映射与 12 项模型/运动/画质检查通过。
- 实际程序验证富文本、公式和表格、文档独立撤销、草稿保护、冲突处理、拖动排序、保存与重启。
- 动效验证固定主轴、有限进退场、关闭时停止惯性、整条拖动、快捷键隔离和系统/应用减少动态效果。
- 恢复验证真实 WebGL 中断、加载过程中再次中断、草稿保留、启动/跳过开场、窗口尺寸与最小化恢复，并要求上下文健康和实际帧继续前进。
- 上一版客户端与 1.2.0 的浅色/暗色开场四帧、阵列、详情及三种模型查看状态共 18 对比较通过，视口 1440×900、DPR 1、相同时间与默认画质。
- 两份 GLB 的字节与 SHA-256 保持一致。新截图在独立示例数据副本中采集，没有个人文档或远程资源。
- Forge 原生文件版本、ASAR 白名单和 ZIP 全部 76 项文件逐项校验通过，发布包不含 RhineLabData。
- 本机原有知识库的 71 个文件在程序替换前后逐文件哈希完全一致。

图像阈值沿用平均通道差 ≤ 2/255、通道差大于 16 的像素比例 ≤ 0.2%。测试时钟采用小步推进并留出 GPU 消费时间；驱动中断造成的无效画面不作为产品对比结果，暗色查看器使用独立会话完成。该检查不替代其他显卡和 DPI 的验证。
